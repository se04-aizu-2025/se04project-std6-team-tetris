# Sort Visualizer

**se04project-std6-team-tetris**

バックエンドで各種ソートアルゴリズムを実行し、その**ソート過程（ログ）をフロントエンドで可視化**するアプリケーションです。  
アルゴリズムの理解や学習を目的としています。

---

## 構成

- **Backend**: C言語（独自HTTPサーバ）
- **Frontend**: React + Vite
- **通信**: REST API（JSON）

---

## 実行方法

### Backend（C言語サーバ）

1. **バックエンドディレクトリへ移動**
   ```bash
   cd backend
   ```

2. **Makefileを用いてビルド**
   ```bash
   make
   ```

3. **サーバ起動**
   
   **Mac/Linux の場合:**
   ```bash
   ./server
   ```
   
   **Windows の場合:**
   ```bash
   .\server.exe
   ```

バックエンドサーバは `http://127.0.0.1:8081` で待ち受けます。

---

### Frontend（React + Vite）

1. **フロントエンドディレクトリへ移動**
   ```bash
   cd frontend
   ```

2. **依存関係のインストール**
   ```bash
   npm install
   ```

3. **開発サーバ起動**
   ```bash
   npm run dev
   ```

起動後、表示されたURL（通常は `http://localhost:5173`）にブラウザでアクセスしてください。

---

## 利用手順

1. ソートアルゴリズムを選択（bubble / merge / insertion / quick など）
2. 配列をランダム生成、または手動入力
3. **START** ボタンを押す
4. ソート過程をステップ操作または自動再生で確認

---

## 実行時の注意点

- **Backend を起動してから Frontend を起動してください**
- フロントエンドからバックエンドへは `POST /sort`（JSON）で通信します
- ブラウザ通信のため、バックエンド側では**CORS**および**OPTIONS**（プリフライトリクエスト）に対応しています

---

## TestEngine の使い方

`npm run dev` で起動したところから、URLに `/test` を付け加えてアクセスしてください。

例: `http://localhost:5173/test`

---

## 機能

- **複数のソートアルゴリズム対応**
  - Bubble Sort
  - Selection Sort
  - Gnome Sort
  - Quick Sort

- **ビジュアライザー機能**
  - ステップバイステップでソート過程を確認
  - 自動再生（Auto Next / Auto Back）
  - スピード調整可能
  - スワップ時のハイライト表示

- **配列入力方法**
  - ランダム生成（1〜20要素）
  - 手動入力（カンマまたはスペース区切り）
